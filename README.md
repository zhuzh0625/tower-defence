# 边境守望 · 可玩原型

固定基地、开放地图、自由布塔的单机浏览器塔防。使用 TypeScript、Phaser 3 和 Vite，游戏运行时不依赖后端或外部素材服务。

## 启动

需要 Node.js 22.12+ 或 24+。Windows 双击 `start-game.cmd`，然后打开 http://127.0.0.1:5178/ 。首次启动会安装依赖，游玩时保留启动窗口。

也可在项目目录执行：

```powershell
npm.cmd install
npm.cmd run dev
```

开发服务只监听本机，端口固定为 5178；端口已被占用时会直接提示，不会悄悄换端口。

## 玩法

- 默认进入主菜单，包含「开始游戏」「测试模式」「资料库」「游戏设置」。开始游戏会新建普通战役，保留原有 30 秒准备、240 金币和 400 基地生命；战场右上角可返回主菜单，返回期间战斗暂停，再次开始会重置本局。
- 测试模式以正常战役为基础，提供可收起的测试面板：瞬间建造与免费建造均覆盖新建、炮塔升级和基地升级；仍遵守占地碰撞、建筑间距和基地等级解锁要求。可选择八种敌人、1–20 数量及方向，在当前建造范围外围安全位置主动创建；暂停时可创建，恢复后行动，准备期的测试敌人也会正常移动和战斗。空间不足时只创建能容纳的数量。测试重开保留开关，重新选择模式则清空开关，普通游戏不会继承测试效果。
- 资料库分为操作规则、炮塔说明、敌人说明，展示图标、属性、解锁条件与特点。游戏设置可调整 0–100% 音效音量（默认静音），支持试听并在此浏览器保存；战场音效按钮可快速静音或恢复上次非零音量。
- 战场占满窗口，初始视角聚焦基地；用滚轮缩放、中键拖拽查看扩大后的地图。资源、波次倒计时和建造栏悬浮在地图上；点击「收起面板」可临时隐藏这些面板，保留暂停等控制。
- 左上角集中显示金币、基地生命、波次和击退数量。顶部情报卡仅显示倒计时（战斗时显示状态）及敌人种类图标，悬停或键盘聚焦图标可查看名称。
- 地图范围为 1560×1080，基地位置固定，初始视角居中于基地；初始生命 400、金币 240。
- 点击主基地可升级，最多 3 级：建造半径为 28.4 / 36 / 44 米；升至 2 / 3 级分别花费 120 / 200 金币、耗时 10 / 15 秒。完成后扩大建造范围，升级期间基地照常受伤，暂停和倍速影响升级进度。
- 初始开放机炮、榴弹炮和冰霜塔。基地升至 2 级解锁穿甲狙击塔，升至 3 级解锁电弧塔；升级完成前保持锁定，建造栏显示解锁条件。
- 第三波起出现紫色菱形远程敌人「掠火者」：基础生命 90、射程 14 米，每 1.6 秒造成 18 点伤害，击杀奖励 15 金币。优先射击范围内最近的炮塔，没有炮塔目标时才攻击射程内的基地；没有目标时继续前进。开火会停下，紫色弹道表示即时命中，与炮塔一样不受中间障碍遮挡。
- 地图没有网格。选择炮塔后，可在基地周围自由点击空地建造，不吸附到固定位置；建造模式下左键始终尝试建造，点击已有建筑或间距不足处提示原因且保留建造模式；右键或 Esc 取消后才可左键选择已有炮塔。
- 圆形预览表示建筑占地，绿色可放、红色不可放。底座必须完整位于虚线范围内，不能与基地、岩石、炮塔或活着的敌人重叠；榴弹炮比机炮占地更大。
- 建筑之间（含基地）至少留出 4.4 米的净通道，保证当前最大体型首领通过。建造时，底座外的小圆圈表示通行预留区，建筑的预留圈不能重叠；最小间距会随最大单位体型自动计算。
- 敌人从基地外围对应方向的不同位置进攻，沿任意方向绕开障碍，单位之间也会避让。通道是否可走取决于敌人体型，首领需要更宽的缺口。
- 地图围绕固定基地向四面展开，外围新增岩石群。敌人出生中心位于当前可建造半径外 7.5 米，随基地升级向外移动；已有敌人位置不变。出生前显示 0.8 秒橙色光圈预警，随后闪光与粒子散开。出生位置避开岩石、建筑与其他敌人；基地升级会把尚未结束的预警移到外围并重新计时。
- 完全封路后，敌人接近并攻击挡路炮塔；建造、拆除或摧毁建筑后重新寻路，有通路时优先绕行。
- 击杀和过关获得金币。点击已建炮塔可升级或拆除；最多 3 级，新建需 5 秒，升至 2 / 3 级需 10 / 15 秒，费用开工时扣除。施工期间不能攻击，但照常占位、受伤和被摧毁；多座炮塔可同时施工。升级完成修复原有损伤，保留施工期间受到的伤害。
- 拆除返还累计投入（含进行中的升级）的 70%，再按剩余耐久比例折算。敌人可以摧毁炮塔。
- 战斗中可以建造、升级和拆除；暂停时停止这些操作。切换到其他浏览器标签页自动暂停。
- 首波准备 30 秒，每波消灭全部敌人后修整 20 秒，随后自动触发下一波；暂停和倍速同时影响波次倒计时与施工。
- 共八波、191 名敌人：第 2 波引入狂奔者，第 3 波引入铁甲卫士与远程敌人，第 4 波引入医疗兵，第 5 波出现首领，第 6 波重装突袭，第 7 波快速突进，第 8 波双首领围攻。敌人抵达基地后持续攻击；消灭全部敌人获胜，基地生命归零失败。
- 提供暂停、1×/2× 速度、音效开关（默认关闭）、玩法说明、重开与结算。

地图操作：滚轮以鼠标位置为中心缩放（缩放下限随窗口尺寸调整，保证地图始终铺满画布），按住中键拖拽，点击「归位」恢复初始视角。拖拽、缩放和窗口调整都会限制整个可见范围在地图内，地图边缘显示深色边带与刻度线。详情框位于屏幕边缘，避免遮挡基地下方。

快捷键：`1` 机炮、`2` 榴弹炮、`3` 冰霜塔、`4` 狙击塔、`5` 电弧塔、`Esc` 取消选择、`空格` 暂停 / 继续。未解锁的炮塔也不能通过快捷键建造。按钮获得焦点时，空格按浏览器原生规则激活该按钮。小屏建造栏可横向滚动。

### 炮塔与搭配

| 炮塔 | 金币 | 基地要求 | 作战用途 |
| --- | ---: | --- | --- |
| 疾风机炮 | 65 | 1 级 | 高射速单体攻击，清理普通敌人 |
| 震荡榴弹炮 | 110 | 1 级 | 范围爆炸，压制密集敌群 |
| 冰霜塔 | 85 | 1 级 | 范围减速 45%，持续 2 秒；重复命中刷新时间，不叠加减速 |
| 穿甲狙击塔 | 150 | 2 级 | 26 米射程、无视护甲，优先铁甲卫士，其次最大生命值高的目标 |
| 电弧塔 | 135 | 3 级 | 连锁命中 3 / 4 / 5 个不同目标（随炮塔等级），每跳保留 70% 伤害，跳跃距离 8 米 |

五类炮塔均可升至 3 级，射程和伤害随等级提升。狙击与电弧即时命中，冰霜、机炮和榴弹炮发射追踪弹；炮塔不受岩石遮挡射线。先建立四面基础防线，再利用修整时间升级基地并搭配新炮塔，避免在首领抵达时让大量炮塔同时停工。

### 敌人特点

| 敌人 | 特点与应对 |
| --- | --- |
| 游荡者 | 普通步兵，机炮适合处理 |
| 疾行者 | 速度快、生命低，避免防线缺口 |
| 破阵者 | 高生命慢速重兵，集中火力 |
| 掠火者 | 远程优先攻击炮塔，注意施工建筑耐久 |
| 铁甲卫士 | 每次减免 6 点伤害，最低仍受 1 点；狙击塔无视护甲 |
| 狂奔者 | 当前生命不高于一半时移速和近战伤害提高 50%，冰霜可限制突进 |
| 医疗兵 | 每 2.5 秒为 10 米内生命比例最低的一名非医疗兵回复 16 点；不超出生命上限，不复活、不互相治疗 |
| 裂地者 | 大体型首领，无护甲，血厚且攻城伤害高；减速配合高伤害火力 |

不同敌人使用不同轮廓和颜色；铁甲有护盾纹样，血条常驻并带银蓝色边框及盾牌护甲值（6），受伤不会消耗护甲；医疗兵有十字标记，狂奔者激怒时出现红色光圈，减速单位显示蓝色光圈。现有 1560×1080 地图足以容纳最高等级部署与外围出生点，本次保留地图尺寸。

## 验证与构建

```powershell
npm.cmd test
npm.cmd run benchmark:navigation
npm.cmd run build
npm.cmd run preview
```

`benchmark:navigation` 使用 13 / 29 座炮塔、8 名混合敌人的独立模拟场景，测量建造、建造后首次更新及随后 240 次更新的 CPU 耗时；它不测绘制帧率，数值随硬件与运行环境变化。

构建产物在 `dist/`，需要通过 HTTP 静态服务访问，不能直接双击其中的 HTML。Phaser 引擎会使首包较大，当前未拆分引擎包。

测试覆盖小数坐标建造、建筑间距边界、最大单位穿过最小建筑间距、完整占地碰撞、不同体型通过窄缝、连续运动防穿透、单位拥挤避让、动态绕行、升级拆除经济、暂停倍速、范围伤害、失败重开，以及基地等级解锁、减速、穿甲、连锁、治疗和狂奔机制。完整八波以正常金币收入、实际施工时间和自动波次推进，逐帧检查碰撞。

## 代码入口

- `src/data.ts`：地图尺寸、障碍物、五种炮塔、八种敌人和八波配置。
- `src/pathfinding.ts`：连续圆形碰撞、扫掠检测和按需检查连线的 A*；按体型复用静态地形样本与可通行连线，不依赖网格，搜索可分段执行。
- `src/engine.ts`：独立战斗模拟；固定 60 Hz 步长，包含经济、伤害、升级、波次和胜负。建造保留未受影响的路线，改道任务共享每次画面更新约 2 毫秒、最多 128 个工作片的预算，倍速子步共享额度。等待期间继续检查碰撞，只有确认无路后才尝试攻击挡路炮塔。
- `src/camera-view.ts`：根据窗口尺寸计算缩放上下限及完整视口边界，防止视角越出地图。
- `src/scene.ts`：Phaser 程序绘制战场、单位、射程与特效，不依赖外部图片。
- `src/main.ts` / `src/style.css` / `src/battlefield.css`：操作面板、快捷键、音效和响应式布局。
- `tests/engine.test.ts`：规则回归与完整八波模拟。
- `tests/advanced-combat.test.ts`：科技解锁与新增战斗机制。
- `tests/navigation-budget.test.ts`：静态缓存复用、分帧改道、过期任务取消及待计算状态的碰撞安全。

## 原型边界

当前为单局体验，不保存进行中的战局；刷新页面会重置。建筑底座、岩石和单位采用圆形碰撞体，炮管、阴影和特效不参与碰撞；狭窄通道可能排队，不模拟推挤或刚体物理。首版难度偏宽容，尚未进行多玩家平衡测试。电脑浏览器体验优先，小屏可点击操作，暂未提供触屏双指缩放手势。
