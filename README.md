# 边境守望 · 可玩原型

固定基地、开放地图、自由布塔的单机浏览器塔防。使用 TypeScript、Phaser 3 和 Vite，游戏运行时不依赖后端或外部素材服务。

## 启动

需要 Node.js 22.12+ 或 24+。Windows 双击 `start-game.cmd`，然后打开 http://127.0.0.1:5178/ 。首次启动会安装依赖，游玩时保留启动窗口。

也可在项目目录执行：

```powershell
npm.cmd install
npm.cmd run dev
```

开发服务只监听本机，端口固定为 5178；端口已被占用时会直接提示，不会悄悄换端口。

## 玩法

- 基地固定在地图中央，初始生命 400、金币 240。
- 疾风机炮花费 65：快速单体攻击；震荡榴弹炮花费 110：慢速范围爆炸。
- 选择炮塔后，点击基地周围虚线范围内的空格建造。可以连续放置，按 Esc 取消。
- 岩石、基地、地图边缘、已有炮塔和敌人当前经过的格子不能建造。
- 敌人从地图外围进攻，沿当前可行路线前进。完全封路后攻击挡路炮塔；重新出现通路后优先绕行。
- 击杀和过关获得金币。点击已建炮塔可升级或拆除；最多 3 级，升级同时完全修复耐久。
- 拆除返还累计投入的 70%，再按剩余耐久比例折算。敌人可以摧毁炮塔。
- 战斗中可以建造、升级和拆除；暂停时停止这些操作。切换到其他浏览器标签页自动暂停。
- 共五波，最后一波有首领。敌人抵达基地后持续攻击；消灭全部敌人获胜，基地生命归零失败。
- 提供暂停、1×/2× 速度、音效开关（默认关闭）、玩法说明、重开与结算。

快捷键：`1` 选择机炮、`2` 选择榴弹炮、`Esc` 取消选择、`空格` 开始波次或暂停 / 继续。按钮获得焦点时，空格按浏览器原生规则激活该按钮。

## 验证与构建

```powershell
npm.cmd test
npm.cmd run build
npm.cmd run preview
```

构建产物在 `dist/`，需要通过 HTTP 静态服务访问，不能直接双击其中的 HTML。Phaser 引擎会使首包较大，当前未拆分引擎包。

测试覆盖放置约束、动态绕行、封路突破、升级拆除经济、暂停倍速、范围伤害、失败重开和正常金币条件下的五波通关。

## 代码入口

- `src/data.ts`：地图尺寸、障碍物、炮塔、敌人和五波配置。
- `src/pathfinding.ts`：普通通路与破障通路的距离场，仅在建筑变化时重算。
- `src/engine.ts`：独立战斗模拟；固定 60 Hz 步长，包含经济、伤害、升级、波次和胜负。
- `src/scene.ts`：Phaser 程序绘制战场、单位、射程与特效，不依赖外部图片。
- `src/main.ts` / `src/style.css`：操作面板、快捷键、音效和响应式布局。
- `tests/engine.test.ts`：规则回归与完整五波模拟。

## 原型边界

当前为单局体验，不保存进行中的战局；刷新页面会重置。网格采用四方向寻路，同类敌人可重叠，不实现复杂拥挤避让。首版难度偏宽容，优先验证布塔与寻路闭环，尚未进行多玩家平衡测试。电脑浏览器体验优先，小屏可点击操作，但没有地图缩放与拖动。
